# RiskManager 4.2.1 Release Notes

RiskManager 4.2.1 是 4.2 正式版的授权稳定性补丁。

## 修复内容

- 修复授权机器码频繁变化导致 `machine_mismatch` 的问题。
- 机器码生成逻辑改为优先使用 Windows `MachineGuid`。
- 移除正常机器码中的硬盘序列号、系统盘卷序列号、MAC 地址等易变化字段。
- 版本号更新为 4.2.1。

## 升级注意

如果客户的授权已经被 4.2 旧机器码绑定，升级 4.2.1 后需要管理员在后台重置该授权的 `machine_hash`，然后让客户重新打开 ATAS 验证授权。

## 不包含

- 不改变交易功能。
- 不改变 4.3 Web 后台功能。
- 不删除或迁移旧授权数据。
