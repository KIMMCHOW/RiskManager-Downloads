# RiskManager 4.2.0 更新日志

## 版本

RiskManager 4.2.0

## 状态

正式版。

## 重点

授权加固、HUD 体验增强、DLL 保护发布流程、风险预设按钮、订单按钮显示开关，以及 Cancel 订单和仓位处理增强。

## 主要变更

- 授权码从本地隐藏文件迁移到 Windows 注册表。
- 注册表授权码使用 Windows DPAPI CurrentUser 加密。
- 支持 4.1 旧授权文件一次性迁移。
- 授权码变更后强制在线验证，并清理旧缓存。
- 不再创建旧隐藏授权文件夹。
- 授权缓存和日志路径调整为 4.2 方案。
- HUD 改为模块化显示结构。
- 支持 HUD 模块开关、模块内小项开关和模块排序。
- 移除旧 HUD 完整 / 精简显示模式。
- 下单模式默认完整。
- 新增风险预设按钮：200 / 500 / 1000 / 2000。
- 每个风险预设按钮可单独启用 / 禁用。
- 新增 MKT / BID/ASK / LMT / STP / Cancel 按钮显示开关。
- 新增 Cancel Button Mode。
- 新增 Cancel 二次确认机制。
- 当前品种订单和仓位范围可撤销当前账户当前品种订单，并调用 ATAS 官方流程处理当前图表品种仓位。
- 修复 Cancel 关闭仓位时同步等待 ATAS 异步接口导致卡死的问题。
- 新增 DLL 保护发布流程文档和 4.2 验收清单。
- 正式版 DLL 已使用 Eziriz .NET Reactor 7.3.0.0 保护。

## 说明

RiskManager 4.2.0 正式版 DLL 文件名为 `RiskManager-4.2.0.dll`，不带 `protected` 字样；该 DLL 已执行保护流程。
