# RiskManager 4.1.0 更新日志

## 版本

RiskManager 4.1.0

## 状态

正式版，已发布。

## 已完成功能

- ATAS Chart Strategy 实现
- HUD 交易面板
- 固定风险金额下单
- Simple 下单模式
- Full 下单模式
- MKT / LMT / STP 入场
- 自动手数计算
- Entry / Stop Loss / Take Profit 订单流程
- RR Target 计算
- SL / TP / OCO 处理
- Tick Value 自动识别和手动覆盖
- 中文 / 英文 HUD
- Supabase 在线授权验证
- machine_hash 绑定
- 本地授权缓存
- 授权码保存在本地隐藏文件 / AppData 配置中

## 已知限制

- 授权码仍存储在本地隐藏文件 / AppData 配置中。
- 注册表 + DPAPI 授权存储规划在 4.2 中改进。
- DLL 保护发布流程规划在 4.2 中完善。
- HUD 模块化规划在 4.2 中完善。
- 风险预设按钮规划在 4.2-D 中开发。
- 产品官网和授权管理后台规划在后续版本中开发。
