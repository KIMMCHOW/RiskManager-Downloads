# RiskManager 4.1.0 归档

此目录保存 RiskManager 4.1.0 正式版归档文件。

## 文件

- RiskManager-4.1.0.dll
- CHANGELOG-4.1.0.md
- RELEASE_NOTES-4.1.0.md
- BUILD_INFO-4.1.0.md
- README-4.1.0.md

## 安装

将 `RiskManager-4.1.0.dll` 复制到 ATAS Strategies 目录：

```text
%AppData%\ATAS\Strategies\
```

然后重启 ATAS，并将 RiskManager 添加为 Chart Strategy。

## 风险提示

RiskManager 是交易执行和风险管理辅助工具，不提供交易信号、投资建议或盈利保证。
