# RiskManager 4.2.2 for ATAS 8.x

本目录保存适用于 ATAS 8.x 的 RiskManager 4.2.2 正式版 DLL。

## 文件

- [RiskManager-4.2.2.dll](RiskManager-4.2.2.dll)
- [CHANGELOG-4.2.2.md](CHANGELOG-4.2.2.md)
- [RELEASE_NOTES-4.2.2.md](RELEASE_NOTES-4.2.2.md)
- [BUILD_INFO-4.2.2.md](BUILD_INFO-4.2.2.md)

## 安装

1. 关闭 ATAS 8.x。
2. 将 `RiskManager-4.2.2.dll` 复制到 `%AppData%\ATAS\Strategies\`。
3. 重启 ATAS。
4. 在图表中添加 RiskManager Chart Strategy。

不要把本目录 DLL 用于 ATAS 7.x。
