# RiskManager 4.2.0 发布说明

这是适用于 ATAS 8.x 的 RiskManager 4.2.0 正式版历史归档。

本版本重点完成授权加固和 HUD 体验增强，同时加入风险预设按钮、订单按钮显示控制、Cancel 二次确认和当前品种订单 / 仓位处理能力。正式 DLL 已通过 .NET Reactor 保护，文件名不带 `protected` 字样。

## 下载文件

```text
RiskManager-4.2.0-ATAS-8.x.dll
```

## 注意事项

- 本版本按当前归档规则归入 ATAS 8.x。
- 实盘使用前请先在模拟盘或回放环境完整测试。
