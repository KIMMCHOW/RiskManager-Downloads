## 安装

1. 关闭 ATAS 8.x。
2. 将 `RiskManager-4.2.0-ATAS-8.x.dll` 复制到 `%AppData%\ATAS\Strategies\`。
3. 重启 ATAS。
4. 在图表中添加 RiskManager Chart Strategy。

本版本是历史单目标正式 DLL，按当前归档规则归入 ATAS 8.x。
