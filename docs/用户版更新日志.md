# RiskManager 用户版更新日志 / RiskManager User Changelog

这里记录 TradingHub 下载中心正式版本的用户可见变更。

This page records user-visible stable release changes in the TradingHub Download Center.

## 4.6.2

状态：正式补丁版。更新入口更贴近 HUD 操作区，并在无需更新时保持隐藏。

Status: stable patch placing the update action closer to the HUD controls and keeping it hidden when no update is needed.

主要更新：

Main changes:

- 有新版本时，更新按钮显示在 `Cancel ALL` 正下方，位置更集中，也不会遮挡图表右上区域。
  When a new release is available, the update button appears directly below `Cancel ALL`, keeping actions together without covering the chart's upper-right area.
- 已是最新版或安装完成后不显示更新按钮；下载、安装及失败重试状态仍会按需显示。
  The button stays hidden when already current and after installation; download, installation, and retry states remain visible when needed.

## 4.6.1

状态：正式补丁版。提升快速成交后原生止损与固定 RR 止盈的挂单可靠性。

Status: stable patch improving native stop-loss and fixed-RR target placement reliability after fast entry fills.

主要更新：

Main changes:

- 当成交与持仓状态更新非常接近时，RiskManager 会在短暂同步窗口内继续完成原生保护单请求，减少成交后止损未挂出的情况。
  When fill and position updates arrive almost together, RiskManager continues the native protection request through the brief synchronization window, reducing missing post-fill stops.
- ENTRY / SL / TP 参考线会保留到保护单请求成功；如果请求最终失败，参考线与错误状态继续可见。
  ENTRY / SL / TP reference lines remain until protection requests succeed; after a terminal failure, the lines and error state stay visible.
- 与持仓同步无关的订单错误不会自动重试，原有失败提示与安全边界保持不变。
  Order errors unrelated to position synchronization are not retried, preserving the existing failure reporting and safety boundary.

## 4.6.0

状态：正式版。止损与固定 RR 止盈改用 ATAS 原生 SL/TP，并简化撤单、HUD 位置和设置分区。

Status: stable. Uses ATAS-native SL/TP for stop protection and fixed-RR targets, with simpler cancellation, HUD placement, and settings organization.

主要更新：

Main changes:

- 入场成交后通过 ATAS 原生订单提交止损与可选止盈；任一侧成交或拒单后会撤销另一侧，Fixed RR 继续负责计算目标价。
  After entry fills, stop protection and the optional target are submitted as native ATAS orders; when either side fills or is rejected, the sibling is canceled, while Fixed RR continues to calculate the target price.
- `Cancel ALL` 一次点击清空当前操作并撤销当前账户、当前品种的全部活动订单，不二次确认，也不会平仓。
  `Cancel ALL` clears the current setup and cancels every active order for the current account and symbol in one click, without confirmation or position close.
- ENTRY / SL / TP 参考线会在入场成交并提交保护订单后移除。
  ENTRY / SL / TP reference lines are removed after the entry fills and protective orders are submitted.
- 风险预设默认值更新为 100 / 200 / 500 / 1000；HUD 位置改为左上、左下、右上、右下四选一，默认右下且首次显示不再从左上角跳位。
  Risk preset defaults are now 100 / 200 / 500 / 1000; HUD placement uses one top-left, bottom-left, top-right, or bottom-right choice, defaults to bottom-right, and no longer flashes at top-left on first draw.
- ATAS X / 8.x 设置页使用 `Trading / Visualization / Orders` 三个原生分区；ATAS 7.x 保留单页设置。
  ATAS X / 8.x settings use native `Trading / Visualization / Orders` tabs; ATAS 7.x keeps its single-page editor.

## 4.5.0

状态：正式版。重新整理设置面板和 HUD 模块顺序，增加独立的水平/垂直位置设置并默认显示在右下角。

Status: stable. Reorganizes settings and HUD module order, adds independent horizontal/vertical placement, and uses bottom-right as the default.

主要更新：

Main changes:

- 设置分组按 License、Interface、HUD Modules、HUD Module Order、HUD Account Module、HUD Risk Module、HUD Tick Module、HUD Price Module、Risk Presets、Order Buttons、Cancel Behavior 排列。
  Settings follow License, Interface, HUD Modules, HUD Module Order, HUD Account Module, HUD Risk Module, HUD Tick Module, HUD Price Module, Risk Presets, Order Buttons, and Cancel Behavior.
- HUD Modules、HUD Module Order 与实际显示统一按 Account、Risk、Tick、Price、Risk Preset、Order、Status 排列。
  HUD Modules, HUD Module Order, and the displayed HUD consistently follow Account, Risk, Tick, Price, Risk Preset, Order, and Status.
- HUD Risk Module 合并风险管理选项，数值项采用显示复选框紧接对应数值输入；Risk Presets 保持独立。
  HUD Risk Module includes the risk-management controls, with each visibility checkbox adjacent to its numeric input; Risk Presets remains separate.
- Fixed RR 设置按 Show RR Ratio、Enable Fixed RR Target、RR Ratio、Show Fixed RR Target 排列；Use Broker OCO 位于 Show Cancel Button 下方。
  Fixed RR settings follow Show RR Ratio, Enable Fixed RR Target, RR Ratio, and Show Fixed RR Target; Use Broker OCO appears below Show Cancel Button.
- Interface 可分别选择左/右与上/下位置，默认组合为右下角。
  Interface lets you select left/right and top/bottom independently, defaulting to bottom-right.

## 4.2.6

状态：正式版。新增受保护图表内更新；ATAS X 与 8.x DLL 内容完全相同；安装完成后提示在 ATAS 主工作区右下角点击“更新指标”。

## 4.2.5

状态：正式版，已发布 ATAS 7.x / 8.x / ATAS X 保护版 DLL。

Status: stable release, with protected DLLs for ATAS 7.x, ATAS 8.x, and ATAS X.

主要更新：

Main changes:

- 修复首次使用 ASK / BID 报价入场时，报价等于最后成交价可能误取消本次下单设置的问题。
  Fixed first-use ASK / BID quote entries being canceled when the quote equals the last traded price.
- 报价入场继续保留正确的止损方向与距离校验，避免不合法的价格关系进入提交。
  Quote entries retain stop-direction and distance checks so invalid price relationships do not reach submission.
- 实时 Best Bid / Best Ask 不可用时安全停止，不使用最后成交价代替报价。
  The setup stops safely when live Best Bid / Best Ask is unavailable instead of substituting the last traded price.
- 提升等待设置止损期间的实时跟价响应。
  Improved live-price tracking while waiting for stop placement.

## 4.2.1

状态：正式版，已发布。

Status: formal release.

主要更新：

Main changes:

- 修复授权机器码过于敏感导致频繁 `machine_mismatch` 的问题。
  Fixed frequent `machine_mismatch` caused by overly sensitive machine-code generation.
- 机器码算法升级为 v2，优先使用 Windows `MachineGuid`。
  Upgraded the machine-code algorithm to v2, preferring Windows `MachineGuid`.
- 不再把硬盘序列号、系统盘卷序列号、MAC 地址等易变化字段混入正常机器码。
  Removed volatile fields such as disk serial number, system-volume serial number, and MAC address from the normal machine code.
- `MachineGuid` 读取失败时，才使用 system UUID、主板序列号、CPU ID 等较稳定字段兜底。
  Uses system UUID, motherboard serial number, CPU ID, and similar stable fields only when `MachineGuid` cannot be read.
- DLL 版本号更新为 `4.2.1`。
  DLL version updated to `4.2.1`.

兼容说明：

Compatibility note:

- 如果旧版本授权在升级后提示设备不匹配，请联系 TradingHub 支持刷新设备绑定状态，然后重新验证。
  If a license from an older release shows a device mismatch after upgrading, contact TradingHub support to refresh the device binding, then verify again.

## 4.2.0

状态：正式版，已发布。

Status: formal release.

主要更新：

Main changes:

- 授权码从本地隐藏文件迁移到 Windows 注册表。
  License Key storage moved from a local hidden file to the Windows Registry.
- 使用 DPAPI 加密保存授权码和授权缓存。
  License Keys and license cache are encrypted with DPAPI.
- 支持 4.1 旧授权文件一次性迁移。
  One-time migration from the old 4.1 license file is supported.
- 授权码变更后强制在线验证。
  Online validation is forced after the License Key changes.
- 完成正式发布包准备流程。
  Completed the stable release package preparation flow.
- 新增风险预设按钮：`100` / `500` / `1000` / `2000`。
  Added risk preset buttons: `100` / `500` / `1000` / `2000`.
- 新增订单按钮显示开关。
  Added a setting to show or hide order buttons.
- 新增 Cancel Button Mode。
  Added Cancel Button Mode.
- 默认 Cancel 只清空 RiskManager 当前操作流程，不直接撤真实订单。
  By default, Cancel only clears the current RiskManager workflow and does not cancel live orders directly.
- 可选支持撤销当前账户、当前图表品种下的未成交订单并处理当前品种仓位。
  Optional mode can cancel working orders for the current account and chart instrument, and handle the current instrument position.
- 修复 Cancel 关闭仓位时同步等待导致 ATAS 卡死的问题。
  Fixed ATAS freezing caused by synchronous waiting when Cancel closes a position.
