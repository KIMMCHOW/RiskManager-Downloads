# RiskManager 用户版更新日志 / RiskManager User Changelog

这里记录 TradingHub 下载中心正式版本的用户可见变更。

This page records user-visible stable release changes in the TradingHub Download Center.

## 4.2.5

状态：正式版，已发布 ATAS 7.x / 8.x / ATAS X 保护版 DLL。

Status: stable release, with protected DLLs for ATAS 7.x, ATAS 8.x, and ATAS X.

主要更新：

Main changes:

- 修复首次使用 ASK / BID 报价入场时，报价等于最后成交价可能误取消本次下单设置的问题。
  Fixed first-use ASK / BID quote entries being canceled when the quote equals the last traded price.
- 报价入场继续保留正确的止损方向与距离校验，避免不合法的价格关系进入提交。
  Quote entries retain stop-direction and distance checks so invalid price relationships do not reach submission.
- 实时 Best Bid / Best Ask 不可用时安全停止，不使用最后成交价代替报价。
  The setup stops safely when live Best Bid / Best Ask is unavailable instead of substituting the last traded price.
- 提升等待设置止损期间的实时跟价响应。
  Improved live-price tracking while waiting for stop placement.

兼容说明：

Compatibility notes:

- ATAS 7.x 用户请下载 [RiskManager-4.2.5-ATAS-7.x.dll](../正式版/7.x/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-7.x.dll)。
  ATAS 7.x users should download [RiskManager-4.2.5-ATAS-7.x.dll](../正式版/7.x/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-7.x.dll).
- ATAS 8.x 用户请下载 [RiskManager-4.2.5-ATAS-8.x.dll](../正式版/8.x/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-8.x.dll)。
  ATAS 8.x users should download [RiskManager-4.2.5-ATAS-8.x.dll](../正式版/8.x/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-8.x.dll).
- ATAS X 用户请下载 [RiskManager-4.2.5-ATAS-X.dll](../正式版/ATAS%20X/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-X.dll)。
  ATAS X users should download [RiskManager-4.2.5-ATAS-X.dll](../正式版/ATAS%20X/RiskManager-4.2.5/RiskManager-4.2.5-ATAS-X.dll).

  DLLs for different ATAS versions are not interchangeable.

## 4.2.4

状态：正式版，已发布 ATAS 7.x / 8.x / ATAS X 保护版 DLL。

Status: formal release, with protected DLLs for ATAS 7.x, ATAS 8.x, and ATAS X.

主要更新：

Main changes:

- Market / Bid / Ask 入场参考线在等待设置 SL 时更快跟随最新价格。
  Market / Bid / Ask entry reference lines track the latest price faster while waiting for SL placement.
- 优化参考线刷新方式，减少首次点击和实时跟价过程中旧价线残留。
  Improved reference-line refresh behavior to reduce stale lines during first click and live price tracking.
- 无效价格关系现在会取消本次下单流程并清空价线，避免用户误以为仍在等待下单。
  Invalid price relationships now cancel the current order setup and clear level lines, preventing users from thinking the setup is still pending.

## 4.2.2

状态：正式版，已发布 ATAS 7.x / 8.x / ATAS X DLL。

Status: formal release, with DLLs for ATAS 7.x, ATAS 8.x, and ATAS X.

主要更新：

Main changes:

- 新增 ATAS 7.x 专用 DLL。
  Added a dedicated DLL for ATAS 7.x.
- 新增 ATAS 8.x 专用 DLL。
  Added a dedicated DLL for ATAS 8.x.
- 新增 ATAS X 正式下载包。
  Added a formal ATAS X download package.
- 默认关闭券商 OCO，提升 Apex / Rithmic 等实盘评测连接的兼容性。
  Broker-side OCO is disabled by default to improve compatibility with Apex / Rithmic-style evaluation connections.
- Entry 单不再携带 OCOGroup，减少入口单被拒风险。
  Entry orders no longer carry OCOGroup, reducing the chance of entry-order rejection.
- 仅在启用券商 OCO 且存在 TP 时，让 SL / TP 共用 OCOGroup。
  SL / TP share OCOGroup only when broker OCO is enabled and a TP order exists.
- 下单请求和拒单原因会写入本地诊断记录，便于排查连接返回的信息。
  Order requests and rejection reasons are written to local diagnostic records to help diagnose connection-side messages.

兼容说明：

Compatibility notes:

- ATAS 7.x 用户请下载 [RiskManager-4.2.2-ATAS-7.x.dll](../正式版/7.x/RiskManager-4.2.2/RiskManager-4.2.2-ATAS-7.x.dll)。

- ATAS X 用户请下载 [RiskManager-4.2.2-ATAS-X.dll](../正式版/ATAS%20X/RiskManager-4.2.2/RiskManager-4.2.2-ATAS-X.dll)。
  ATAS X users should download [RiskManager-4.2.2-ATAS-X.dll](../正式版/ATAS%20X/RiskManager-4.2.2/RiskManager-4.2.2-ATAS-X.dll).

## 4.2.1

状态：正式版，已发布。

Status: formal release.

主要更新：

Main changes:

- 修复授权机器码过于敏感导致频繁 `machine_mismatch` 的问题。
  Fixed frequent `machine_mismatch` caused by overly sensitive machine-code generation.
- 机器码算法升级为 v2，优先使用 Windows `MachineGuid`。
  Upgraded the machine-code algorithm to v2, preferring Windows `MachineGuid`.
- 不再把硬盘序列号、系统盘卷序列号、MAC 地址等易变化字段混入正常机器码。
  Removed volatile fields such as disk serial number, system-volume serial number, and MAC address from the normal machine code.
- `MachineGuid` 读取失败时，才使用 system UUID、主板序列号、CPU ID 等较稳定字段兜底。
  Uses system UUID, motherboard serial number, CPU ID, and similar stable fields only when `MachineGuid` cannot be read.
- DLL 版本号更新为 `4.2.1`。
  DLL version updated to `4.2.1`.

兼容说明：

Compatibility note:

- 如果旧版本授权在升级后提示设备不匹配，请联系 TradingHub 支持刷新设备绑定状态，然后重新验证。
  If a license from an older release shows a device mismatch after upgrading, contact TradingHub support to refresh the device binding, then verify again.

## 4.2.0

状态：正式版，已发布。

Status: formal release.

主要更新：

Main changes:

- 授权码从本地隐藏文件迁移到 Windows 注册表。
  License Key storage moved from a local hidden file to the Windows Registry.
- 使用 DPAPI 加密保存授权码和授权缓存。
  License Keys and license cache are encrypted with DPAPI.
- 支持 4.1 旧授权文件一次性迁移。
  One-time migration from the old 4.1 license file is supported.
- 授权码变更后强制在线验证。
  Online validation is forced after the License Key changes.
- 完成正式发布包准备流程。
  Completed the stable release package preparation flow.
- 新增风险预设按钮：`100` / `500` / `1000` / `2000`。
  Added risk preset buttons: `100` / `500` / `1000` / `2000`.
- 新增订单按钮显示开关。
  Added a setting to show or hide order buttons.
- 新增 Cancel Button Mode。
  Added Cancel Button Mode.
- 默认 Cancel 只清空 RiskManager 当前操作流程，不直接撤真实订单。
  By default, Cancel only clears the current RiskManager workflow and does not cancel live orders directly.
- 可选支持撤销当前账户、当前图表品种下的未成交订单并处理当前品种仓位。
  Optional mode can cancel working orders for the current account and chart instrument, and handle the current instrument position.
- 修复 Cancel 关闭仓位时同步等待导致 ATAS 卡死的问题。
  Fixed ATAS freezing caused by synchronous waiting when Cancel closes a position.

  Supports Simple / Full order modes.
