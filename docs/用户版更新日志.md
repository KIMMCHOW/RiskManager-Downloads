# RiskManager 用户版更新日志

这里记录公开下载仓库中的正式版变更。开发中版本、后台系统和内部发布流程不在这里展开。

## 4.2.2

状态：正式版，已发布 ATAS 7.x / 8.x 双版本 DLL。

主要更新：

- 新增 ATAS 7.x 专用 DLL。
- 新增 ATAS 8.x 专用 DLL。
- 默认关闭券商 OCO，提升 Apex / Rithmic 等实盘评测连接的兼容性。
- Entry 单不再携带 OCOGroup，减少入口单被拒风险。
- 仅在启用券商 OCO 且存在 TP 时，让 SL / TP 共用 OCOGroup。
- 下单请求和拒单原因会写入本地授权日志，便于排查连接返回的真实错误。

兼容说明：

- ATAS 7.x 用户请下载 `正式版/7.x/RiskManager-4.2.2/RiskManager-4.2.2-ATAS-7.x.dll`。
- ATAS 8.x 用户请下载 `正式版/8.x/RiskManager-4.2.2/RiskManager-4.2.2-ATAS-8.x.dll`。
- 两个 DLL 不能混用。

## 4.2.1

状态：正式版，已发布。

主要更新：

- 修复授权机器码过于敏感导致频繁 `machine_mismatch` 的问题。
- 机器码算法升级为 v2，优先使用 Windows `MachineGuid`。
- 不再把硬盘序列号、系统盘卷序列号、MAC 地址等易变化字段混入正常机器码。
- `MachineGuid` 读取失败时，才使用 system UUID、主板序列号、CPU ID 等较稳定字段兜底。
- DLL 版本号更新为 `4.2.1`。

兼容说明：

- 已经用 4.2 旧算法绑定过的授权，升级 4.2.1 后需要在后台重置一次 `machine_hash`，再让客户重新验证。

## 4.2.0

状态：正式版，已发布。

主要更新：

- 授权码从本地隐藏文件迁移到 Windows 注册表。
- 使用 DPAPI 加密保存授权码和授权缓存。
- 支持 4.1 旧授权文件一次性迁移。
- 授权码变更后强制在线验证。
- 完成 .NET Reactor 保护发布流程。
- 新增风险预设按钮：`100` / `500` / `1000` / `2000`。
- 新增订单按钮显示开关。
- 新增 Cancel Button Mode。
- 默认 Cancel 只清空 RiskManager 当前操作流程，不直接撤真实订单。
- 可选支持撤销当前账户、当前图表品种下的未成交订单并处理当前品种仓位。
- 修复 Cancel 关闭仓位时同步等待导致 ATAS 卡死的问题。

## 4.1.0

状态：正式版，已发布。

主要更新：

- 完成 ATAS Chart Strategy 基础版本。
- 支持固定金额风险下单、图表选价和自动手数计算。
- 支持 Simple / Full 下单模式。
- 支持 MKT / LMT / STP 入场。
- 支持 Entry / Stop Loss / Take Profit 基础订单流程。
- 支持 RR Target、SL / TP / OCO 处理。
- 支持 Tick Value 自动识别和手动覆盖。
- 支持中文 / 英文 HUD。
- 接入 Supabase 在线授权验证。
- 支持 `machine_hash` 机器绑定和本地授权缓存。
