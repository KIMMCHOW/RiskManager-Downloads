# RiskManager 用户使用教程 / RiskManager User Guide

RiskManager 是用于 ATAS 的图表交易策略工具。用户输入每笔交易愿意承担的止损金额，在图表上选择入场方式和止损价后，RiskManager 会自动计算下单手数，并提交入场单、止损单，以及可选的 RR 止盈单。

RiskManager is an ATAS Chart Strategy for risk-based order entry. You enter the maximum loss amount you are willing to take per trade, choose the entry method and stop price on the chart, and RiskManager calculates position size automatically before submitting the entry order, stop order, and optional RR target order.

## 重要提醒 / Important Notes

1. 这是 ATAS 的 Chart Strategy，不是普通 Indicator。
   This is an ATAS Chart Strategy, not a regular Indicator.
2. DLL 应放入 ATAS 的 `Strategies` 目录。
   Put the DLL into the ATAS `Strategies` folder.
3. 实盘使用前，请先在模拟账户或回放环境中完整测试。
   Before live trading, test the full workflow in simulation or replay.
4. 本工具只负责按设置发送订单，不保证成交价格、滑点、网络、交易所或券商执行结果。
   This tool only sends orders according to your settings; it cannot guarantee fills, slippage, network reliability, exchange behavior, or broker execution.

## 一、安装方法 / Installation

1. 关闭 ATAS。
   Close ATAS.

2. 找到与你的 ATAS 大版本匹配的发布 DLL。
   Find the release DLL that matches your ATAS major version.

```text
RiskManager-4.6.1-ATAS-8.x.dll
RiskManager-4.6.1-ATAS-7.x.dll
RiskManager-4.6.1-ATAS-X.dll
```

请按 ATAS 名称选择 DLL；X 与 8.x 文件内容完全相同，7.x 为独立构建。自动安装后，请在 ATAS 主工作区右下角点击“更新指标”。

Choose the DLL name matching ATAS. X and 8.x are byte-identical; 7.x remains separate. After automatic installation, click Update indicators in the bottom-right corner of the ATAS main workspace.

3. 将 DLL 复制到 ATAS 策略目录。
   Copy the DLL into the ATAS strategies folder.

```text
%AppData%\ATAS\Strategies\
```

可以在 Windows 资源管理器地址栏输入上面的路径并回车打开。

You can paste the path above into Windows Explorer and press Enter.

4. 重新启动 ATAS。
   Restart ATAS.

5. 打开图表并添加 RiskManager。
   Open a chart and add RiskManager.

```text
右键图表 -> 图表策略 / Chart Strategies -> 添加 RiskManager
Right-click chart -> Chart Strategies -> Add RiskManager
```

6. 添加后，在 ATAS 底部的“交易策略 / Trading Strategies”列表中，或图表左上角策略列表中，勾选启用。
   After adding it, enable it from the ATAS bottom `Trading Strategies` list or from the strategy list in the top-left area of the chart.

策略设置面板里的 `IsActivated` 是运行状态显示 / 控制项。实际使用时，请确认底部策略列表已经启用，并且 HUD 里 `Active` 显示为 `ON`。

`IsActivated` in the strategy settings panel is a runtime state/control field. In actual use, confirm that the strategy is enabled in the bottom strategy list and that the HUD shows `Active = ON`.

## 二、授权码设置 / License Key Setup

首次使用前需要填写授权码。

You need to enter a License Key before first use.

1. 打开 RiskManager 的策略设置。
   Open RiskManager strategy settings.
2. 找到 `授权 / License` 分组中的 `License Key / 授权码`。
   Find `License Key / 授权码` under the `授权 / License` group.
3. 输入你的授权码。
   Enter your License Key.
4. 保存设置并启用策略。
   Save settings and enable the strategy.

在线验证成功后，RiskManager 会保存授权状态。以后你在 GC、ES、NQ 等其他图表再次添加 RiskManager 时，如果策略设置面板里的 License Key 为空，RiskManager 会自动读取已保存的授权码并验证。你不需要每个图表重复输入授权码。

After online validation succeeds, RiskManager stores the license state. When you add RiskManager to other charts such as GC, ES, or NQ later, it can load and validate the saved License Key automatically if the setting panel field is empty. You do not need to enter the key again for every chart.

如果授权码为空、无效、过期、绑定机器不匹配，或首次验证时网络不可用，HUD 会显示授权相关提示，并且无法正常下单。

If the key is missing, invalid, expired, bound to a different machine, or cannot be validated due to network failure during first validation, the HUD will show a license warning and order entry will be blocked.

## 三、主要参数说明 / Main Settings

### 1. 止损金额($) / SL Amount ($)

每笔交易计划承担的最大止损金额。

Maximum planned loss amount per trade.

示例：设置为 `250`，表示这笔交易按止损价计算，理论最大亏损约为 250 美元。

Example: `250` means the theoretical maximum loss is about USD 250 based on the selected stop price.

### 2. RR 比例 / RR Ratio

启用 RR 止盈时使用的风险回报比。

Risk-reward ratio used when RR target is enabled.

示例：入场价 100，止损价 95，RR 设置为 2，则多单止盈价为 110。

Example: entry 100, stop 95, RR 2 means a long target price of 110.

### 3. 启用固定 RR 止盈 / Enable Fixed RR Target

开启：自动计算并提交 TP 止盈单。

On: automatically calculate and submit a TP target order.

关闭：只提交入场单和止损单，不提交止盈单。

Off: submit only the entry order and stop order, without a target order.

### 4. UI 样式 / UI Style

`HUD`：在图表上显示可操作面板。

`HUD`: shows the interactive panel on the chart.

`折叠栏 / Collapsed`：不显示 HUD，只保留策略设置。

`Collapsed`: hides the HUD and keeps only the strategy settings.

日常下单建议使用 HUD。

HUD mode is recommended for daily order entry.

### 5. 界面语言 / Interface Language

HUD 与设置界面自动跟随 ATAS 的界面语言。如需切换，请在 ATAS 主窗口选择 Language 后重新打开相关窗口。

The HUD and settings automatically follow the ATAS interface language. To switch languages, choose Language in the ATAS main window and reopen the affected windows.

### 6. 下单模式 / Order Entry Mode

`简单 / Simple`：通过两次点击图表完成下单。

`Simple`: complete order setup with two chart clicks.

`完整 / Full`：先选择买 / 卖方向和订单类型，再点击图表价格。

`Full`: choose Buy/Sell direction and order type first, then click chart prices.

日常精确操作建议使用 `Full`。

`Full` is recommended for precise daily trading.

默认 `0` 表示自动识别常见品种 Tick Value。如果自动识别不准确，可以手动填写。

简单模式适合快速根据图表点击完成下单。

For short trades, stop must be above entry.
```

## 七、撤销全部订单 / Cancel ALL

点击 HUD 中的 `Cancel ALL` 会立即清空当前入场、止损、止盈与手数选择，并撤销当前账户、当前图表品种的全部活动订单。

Clicking `Cancel ALL` immediately clears the current entry, stop, target, and quantity selection, then cancels every active order for the current account and chart instrument.

该行为固定启用，不提供范围或模式设置，也不需要二次确认。撤单范围包括手动订单、其他策略订单和原生 SL/TP。

`Cancel ALL` never closes a position. Existing positions remain unchanged; use the separate ATAS close-position action when a position must be closed.

## 八、仓位计算逻辑 / Position Sizing Logic

RiskManager 使用以下逻辑计算手数：

RiskManager calculates quantity with the following logic:

```text
Tick 距离 = |入场价 - 止损价| / TickSize
Tick distance = |entry - stop| / TickSize

单手风险 = Tick 距离 * 每 Tick 价值
Risk per contract = tick distance * tick value

下单手数 = 向下取整(止损金额 / 单手风险)
Quantity = floor(SL Amount / risk per contract)
```

如果计算结果小于 1，则最少为 1 手。

If the result is less than 1, the minimum quantity is 1.

示例 / Example:

```text
止损金额 = 250 美元
SL Amount = USD 250

入场价到止损价距离 = 20 Tick
Entry-to-stop distance = 20 ticks

每 Tick 价值 = 0.50 美元
Tick Value = USD 0.50

单手风险 = 20 * 0.50 = 10 美元
Risk per contract = 20 * 0.50 = USD 10

手数 = 250 / 10 = 25 手
Quantity = 250 / 10 = 25 contracts
```

## 九、RR 止盈逻辑 / RR Target Logic

当 `Enable Fixed RR Target` 开启时，RiskManager 会根据 `RR Ratio` 自动计算止盈价。

When `Enable Fixed RR Target` is on, RiskManager calculates the target price from `RR Ratio`.

做多 / Long:

```text
止盈价 = 入场价 + (入场价 - 止损价) * RR
Target = entry + (entry - stop) * RR
```

做空 / Short:

```text
止盈价 = 入场价 - (止损价 - 入场价) * RR
Target = entry - (stop - entry) * RR
```

如果 `Enable Fixed RR Target` 关闭，则不计算 TP、不提交 TP 止盈单，只提交入场单和止损单。

If `Enable Fixed RR Target` is off, RiskManager does not calculate or submit a TP order. It submits only the entry and stop orders.

## 十、订单提交逻辑 / Order Submission Logic

RiskManager 当前使用普通订单实现入场、止损和止盈：

RiskManager currently uses regular orders for entry, stop, and target:

```text
Entry：Market / Limit / Stop，由下单模式决定。
Entry: Market / Limit / Stop, determined by entry mode.

SL：Stop 订单。
SL: Stop order.

TP：ATAS 原生 Take-Profit，仅在启用 RR 止盈时创建。
TP: ATAS-native Take-Profit, created only when RR target is enabled.
```

一般流程 / General flow:

1. 先提交 Entry 入场单。
   Submit the entry order first.
2. Entry 成交后，通过 ATAS 原生订单提交 SL 止损和可选 TP 止盈，并移除 ENTRY / SL / TP 参考线。
   After entry fills, submit native ATAS SL protection and the optional TP target, then remove the ENTRY / SL / TP reference lines.
3. SL 或 TP 任一侧成交或拒单后，工具会撤销另一侧。
   When either SL or TP fills or is rejected, the tool cancels the sibling order.

## 十一、常见问题 / FAQ

### 1. HUD 没出现 / HUD Does Not Appear

检查 `UI Style` 是否为 `HUD`，策略是否已添加到当前图表，以及 ATAS 底部策略列表是否启用 RiskManager。

Check that `UI Style` is `HUD`, the strategy has been added to the current chart, and RiskManager is enabled in the ATAS bottom strategy list.

### 2. HUD 显示中文乱码 / Chinese Text Looks Garbled

在 ATAS 主窗口将 Language 切换为 `English`，然后重新打开相关窗口。

Switch Language to `English` in the ATAS main window, then reopen the affected windows.

### 3. 点击按钮后不能下单 / Buttons Do Not Submit Orders

检查授权码、HUD 状态栏、策略启用状态、交易账户、当前品种可交易状态和 Tick Value。

Check License Key, HUD status, strategy activation, selected trading account, symbol tradability, and Tick Value.

### 4. BID / ASK 点击后没有进入下单流程 / BID Or ASK Does Not Start Workflow

当前 Best Bid 或 Best Ask 可能不可用。请确认行情连接正常，并且当前品种有实时买卖价。

Current Best Bid or Best Ask may be unavailable. Confirm that market data is connected and the symbol has live bid/ask prices.

### 5. 提示止损价格无效 / Stop Price Invalid

做多时止损必须低于入场价；做空时止损必须高于入场价。

For long trades, stop must be below entry. For short trades, stop must be above entry.

### 6. 提示 Limit 或 Stop 价格无效 / Limit Or Stop Price Invalid

```text
Buy Limit 必须低于市场价。
Buy Limit must be below market price.

Sell Limit 必须高于市场价。
Sell Limit must be above market price.

Buy Stop 必须高于市场价。
Buy Stop must be above market price.

Sell Stop 必须低于市场价。
Sell Stop must be below market price.
```

### 7. 自动手数看起来不对 / Auto Quantity Looks Wrong

优先检查每 Tick 价值是否正确。如果自动识别不适合当前品种，请在 `Tick Value ($)` 中手动填写。

First check whether Tick Value is correct. If auto-detection is not suitable for the symbol, enter it manually in `Tick Value ($)`.

### 8. 为什么至少下 1 手 / Why Minimum Quantity Is 1

当计算出的手数小于 1 时，RiskManager 会按 1 手处理。请确认止损金额和止损距离是否适合当前品种，避免实际风险超过预期。

When calculated quantity is less than 1, RiskManager uses 1 contract. Confirm that SL Amount and stop distance are suitable for the symbol to avoid exceeding expected risk.

### 9. Cancel ALL 后仍有订单 / Orders Remain After Cancel ALL

确认当前账户和图表品种正确，并检查订单是否仍处于活动状态。`Cancel ALL` 不会平仓，因此已有仓位继续保留属于正常行为。

## 八、仓位计算逻辑 / Position Sizing Logic

RiskManager 使用以下逻辑计算手数：

RiskManager calculates quantity with the following logic:

```text
Tick 距离 = |入场价 - 止损价| / TickSize
Tick distance = |entry - stop| / TickSize

单手风险 = Tick 距离 * 每 Tick 价值
Risk per contract = tick distance * tick value

下单手数 = 向下取整(止损金额 / 单手风险)
Quantity = floor(SL Amount / risk per contract)
```

如果计算结果小于 1，则最少为 1 手。

If the result is less than 1, the minimum quantity is 1.

示例 / Example:

```text
止损金额 = 250 美元
SL Amount = USD 250

入场价到止损价距离 = 20 Tick
Entry-to-stop distance = 20 ticks

每 Tick 价值 = 0.50 美元
Tick Value = USD 0.50

单手风险 = 20 * 0.50 = 10 美元
Risk per contract = 20 * 0.50 = USD 10

手数 = 250 / 10 = 25 手
Quantity = 250 / 10 = 25 contracts
```

## 九、RR 止盈逻辑 / RR Target Logic

当 `Enable Fixed RR Target` 开启时，RiskManager 会根据 `RR Ratio` 自动计算止盈价。

When `Enable Fixed RR Target` is on, RiskManager calculates the target price from `RR Ratio`.

做多 / Long:

```text
止盈价 = 入场价 + (入场价 - 止损价) * RR
Target = entry + (entry - stop) * RR
```

做空 / Short:

```text
止盈价 = 入场价 - (止损价 - 入场价) * RR
Target = entry - (stop - entry) * RR
```

如果 `Enable Fixed RR Target` 关闭，则不计算 TP、不提交 TP 止盈单，只提交入场单和止损单。

If `Enable Fixed RR Target` is off, RiskManager does not calculate or submit a TP order. It submits only the entry and stop orders.

## 十、订单提交逻辑 / Order Submission Logic

RiskManager 当前使用普通订单实现入场、止损和止盈：

RiskManager currently uses regular orders for entry, stop, and target:

```text
Entry：Market / Limit / Stop，由下单模式决定。
Entry: Market / Limit / Stop, determined by entry mode.

SL：Stop 订单。
SL: Stop order.

TP：ATAS 原生 Take-Profit，仅在启用 RR 止盈时创建。
TP: ATAS-native Take-Profit, created only when RR target is enabled.
```

一般流程 / General flow:

1. 先提交 Entry 入场单。
   Submit the entry order first.
2. Entry 成交后，通过 ATAS 原生订单提交 SL 止损和可选 TP 止盈，并移除 ENTRY / SL / TP 参考线。
   After entry fills, submit native ATAS SL protection and the optional TP target, then remove the ENTRY / SL / TP reference lines.
3. SL 或 TP 任一侧成交或拒单后，工具会撤销另一侧。
   When either SL or TP fills or is rejected, the tool cancels the sibling order.

检查 `UI Style` 是否为 `HUD`，策略是否已添加到当前图表，以及 ATAS 底部策略列表是否启用 RiskManager。

Check that `UI Style` is `HUD`, the strategy has been added to the current chart, and RiskManager is enabled in the ATAS bottom strategy list.

### 2. HUD 显示中文乱码 / Chinese Text Looks Garbled

在 ATAS 主窗口将 Language 切换为 `English`，然后重新打开相关窗口。

Switch Language to `English` in the ATAS main window, then reopen the affected windows.

### 3. 点击按钮后不能下单 / Buttons Do Not Submit Orders

检查授权码、HUD 状态栏、策略启用状态、交易账户、当前品种可交易状态和 Tick Value。

Check License Key, HUD status, strategy activation, selected trading account, symbol tradability, and Tick Value.

### 4. BID / ASK 点击后没有进入下单流程 / BID Or ASK Does Not Start Workflow

当前 Best Bid 或 Best Ask 可能不可用。请确认行情连接正常，并且当前品种有实时买卖价。

Current Best Bid or Best Ask may be unavailable. Confirm that market data is connected and the symbol has live bid/ask prices.

### 5. 提示止损价格无效 / Stop Price Invalid

做多时止损必须低于入场价；做空时止损必须高于入场价。

For long trades, stop must be below entry. For short trades, stop must be above entry.

### 6. 提示 Limit 或 Stop 价格无效 / Limit Or Stop Price Invalid

```text
Buy Limit 必须低于市场价。
Buy Limit must be below market price.

Sell Limit 必须高于市场价。
Sell Limit must be above market price.

Buy Stop 必须高于市场价。
Buy Stop must be above market price.

Sell Stop 必须低于市场价。
Sell Stop must be below market price.
```

### 7. 自动手数看起来不对 / Auto Quantity Looks Wrong

优先检查每 Tick 价值是否正确。如果自动识别不适合当前品种，请在 `Tick Value ($)` 中手动填写。

First check whether Tick Value is correct. If auto-detection is not suitable for the symbol, enter it manually in `Tick Value ($)`.

### 8. 为什么至少下 1 手 / Why Minimum Quantity Is 1

当计算出的手数小于 1 时，RiskManager 会按 1 手处理。请确认止损金额和止损距离是否适合当前品种，避免实际风险超过预期。

When calculated quantity is less than 1, RiskManager uses 1 contract. Confirm that SL Amount and stop distance are suitable for the symbol to avoid exceeding expected risk.

### 9. Cancel ALL 后仍有订单 / Orders Remain After Cancel ALL

确认当前账户和图表品种正确，并检查订单是否仍处于活动状态。`Cancel ALL` 不会平仓，因此已有仓位继续保留属于正常行为。

Confirm that the current account and chart symbol are correct, and check whether the order is still active. `Cancel ALL` never closes positions, so an existing position remaining open is expected.

## 十二、实盘前检查清单 / Pre-Live Checklist

每次实盘使用前，建议确认：

Before each live trading session, confirm:

1. 授权码有效。 / License Key is valid.
2. 当前账户正确。 / Current account is correct.
3. 当前品种正确。 / Current symbol is correct.
4. 策略状态为 ON。 / Strategy status is ON.
5. `SL Amount` 是本次愿意承担的最大亏损金额。 / `SL Amount` is the maximum loss you are willing to take for this trade.
6. `Tick Value` 正确。 / `Tick Value` is correct.
7. `RR Target` 是否按计划开启或关闭。 / `RR Target` is enabled or disabled as planned.
8. `Order Entry Mode` 是否符合当前操作习惯。 / `Order Entry Mode` matches your workflow.
9. 已在模拟环境测试过当前品种的下单、成交、止损和止盈流程。 / You have tested order entry, fills, stops, and targets for this symbol in simulation.
10. 使用 BID / ASK 前确认实时行情和买卖价正常。 / Before using BID / ASK, confirm live data and bid/ask prices are normal.
11. 点击 `Cancel ALL` 前确认当前账户和图表品种正确；该操作会撤销该范围内全部活动订单，但不会平仓。 / Before clicking `Cancel ALL`, confirm the current account and chart symbol; it cancels every active order in that scope but never closes the position.

## 十三、风险提示 / Risk Warning

交易存在风险。RiskManager 只能按照输入参数和当前市场数据计算订单，不控制滑点、跳空、网络延迟、交易所拒单、券商风控限制、ATAS 连接异常、行情数据异常、手动改动或取消订单等情况。

Trading involves risk. RiskManager can only calculate and submit orders according to your inputs and current market data. It does not control slippage, gaps, network latency, exchange rejections, broker risk limits, ATAS connection issues, market data errors, or manual order changes/cancellations.

实盘前请务必使用模拟账户验证，并确认你理解每一种订单类型的行为。

Before live trading, verify everything in simulation and make sure you understand how each order type behaves.
