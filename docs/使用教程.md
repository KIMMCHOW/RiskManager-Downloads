# RiskManager 用户使用教程

RiskManager 是用于 ATAS 的图表交易策略工具。它的主要用途是：用户输入每笔交易愿意承担的止损金额，然后在图表上选择入场方式和止损价，工具会自动计算下单手数，并提交入场单、止损单，以及可选的 RR 止盈单。

重要提醒：

1. 这是 ATAS 的 Chart Strategy，不是普通 Indicator。
2. DLL 应放入 ATAS 的 Strategies 目录。
3. 实盘使用前，请先在模拟账户或回放环境中完整测试。
4. 本工具只负责按设置发送订单，不保证成交价格、滑点、网络、交易所或券商执行结果。

## 一、安装方法

1. 关闭 ATAS。

2. 找到发布文件：

```text
RiskManager-4.2.2-ATAS-8.x.dll
RiskManager-4.2.2-ATAS-7.x.dll
```

请根据自己的 ATAS 大版本选择 `正式版/7.x/` 或 `正式版/8.x/` 目录中的 DLL，不要混用。

3. 将 DLL 复制到 ATAS 策略目录：

```text
%AppData%\ATAS\Strategies\
```

可以在 Windows 资源管理器地址栏输入上面的路径并回车打开。

4. 重新启动 ATAS。

5. 打开一个图表，添加 RiskManager：

```text
右键图表 -> 图表策略 / Chart Strategies -> 添加 RiskManager
```

6. 添加后，在 ATAS 底部的“交易策略 / Trading Strategies”列表中，或图表左上角策略列表中，勾选启用。

注意：

策略设置面板里的 IsActivated 是运行状态显示 / 控制项。实际使用时，请确认底部策略列表已经启用，并且 HUD 里 Active 显示为 ON。

## 二、授权码设置

首次使用前需要填写授权码。

1. 打开 RiskManager 的策略设置。

2. 找到：

```text
授权 / License
License Key / 授权码
```

3. 输入你的授权码。

4. 保存设置并启用策略。

在线验证成功后，RiskManager 会保存授权状态。

以后你在 GC、ES、NQ 等其他图表再次添加 RiskManager 时，如果策略设置面板里的 License Key 为空，RiskManager 会自动读取已保存的授权码并验证。你不需要每个图表重复输入授权码。

如果授权码为空、无效、过期、绑定机器不匹配，或首次验证时网络不可用，HUD 会显示授权相关提示，并且无法正常下单。

## 三、主要参数说明

在 RiskManager 策略设置里可以看到以下常用参数。

### 1. 止损金额($) / SL Amount ($)

每笔交易计划承担的最大止损金额。

示例：设置为 250，表示这笔交易按止损价计算，理论最大亏损约为 250 美元。

### 2. RR 比例 / RR Ratio

启用 RR 止盈时使用的风险回报比。

示例：入场价 100，止损价 95，RR 设置为 2，则多单止盈价为 110。

### 3. 启用 RR 止盈 / Enable RR Target

开启：自动计算并提交止盈单 TP。

关闭：只提交入场单和止损单，不提交止盈单。

### 4. UI 样式 / UI Style

HUD：在图表上显示可操作面板。

折叠栏 / Collapsed：不显示 HUD，只保留策略设置。

日常下单建议使用 HUD。

### 5. HUD 语言 / HUD Language

可选择英文或中文。

如果你的 ATAS 或系统环境下中文显示异常，可以切换为 English。

### 6. 下单模式 / Order Entry Mode

简单 / Simple：通过两次点击图表完成下单。

完整 / Full：先选择买 / 卖方向和订单类型，再点击图表价格。

日常精确操作建议使用 Full。

### 7. 每 Tick 价值($) / Tick Value ($)

默认 0，表示自动识别常见品种 Tick Value。

如果自动识别不准确，可以手动填写。

常见示例：

```text
ES   每 Tick = 12.50 美元
MES  每 Tick = 1.25 美元
NQ   每 Tick = 5.00 美元
MNQ  每 Tick = 0.50 美元
GC   每 Tick = 10.00 美元
MGC  每 Tick = 1.00 美元
```

### 8. 风险预设按钮 / Risk Presets

HUD 默认提供常用风险金额按钮：

```text
200 / 500 / 1000 / 2000
```

点击按钮后，会快速切换当前 SL Amount。

你也可以在设置中启用、禁用或修改每个预设金额。

### 9. HUD 模块显示

RiskManager 的 HUD 可以按模块显示或隐藏，例如：

- 风险预设模块
- 账户模块
- Tick 模块
- 风险模块
- 价格模块
- 订单模块
- 状态模块

你可以根据自己的交易习惯关闭不需要的模块，也可以调整模块顺序。

## 四、HUD 面板说明

HUD 默认显示在图表上，可以拖动位置。

常见字段含义：

SL Amount ($)
: 当前每笔交易止损金额。

RR Target / RR Ratio
: RR 止盈状态和 RR 数值。显示 OFF 表示未启用止盈单。

Active / Account
: 策略是否启用，以及当前选择的账户。

Symbol
: 当前交易品种。

Tick Value
: 当前每 Tick 价值。Auto 表示自动识别，Manual 表示手动填写。

Entry
: 当前选择的入场价。

Stop
: 当前选择的止损价。

Tick Distance
: 入场价到止损价之间的 Tick 数。

Auto Qty
: 根据止损金额自动计算出的下单手数。

Target
: 自动计算的止盈价。RR 止盈关闭时显示 OFF。

Status
: 当前状态提示，例如等待点击入场价、等待点击止损价、订单已发送、授权失败等。

## 五、简单下单模式

简单模式适合快速根据图表点击完成下单。

操作步骤：

1. 确认参数：

```text
SL Amount 设置为你愿意亏损的金额。
Enable RR Target 按需要开启或关闭。
RR Ratio 设置为想要的风险回报比。
Order Entry Mode 选择 Simple。
```

2. 点击 HUD 里的 Order Mode / 下单模式。

此时状态会变为：

```text
Click entry price / 点击入场价
```

3. 在图表上点击入场价。

4. 再在图表上点击止损价。

5. RiskManager 会自动计算：

```text
Tick 距离
每手风险
下单手数
止盈价（如果启用 RR 止盈）
```

6. 计算通过后，工具会发送入场订单。

简单模式的方向判断规则：

```text
入场价低于当前市场价：Buy Limit
入场价高于当前市场价：Sell Limit
```

止损价规则：

```text
做多时，止损价必须低于入场价。
做空时，止损价必须高于入场价。
```

## 六、完整下单模式

完整模式适合明确指定买卖方向和订单类型。

先将 Order Entry Mode 设置为 Full。HUD 底部会出现 Buy / Sell 两列：

```text
[ 买 ]       [ 卖 ]
[ MKT ]      [ MKT ]
[ BID ]      [ ASK ]
[ LMT ]      [ LMT ]
[ STP ]      [ STP ]
     [ Cancel ]
```

其中：

```text
MKT = Market 市价单
BID = 使用当前 Best Bid 作为 Buy Limit 入场价
ASK = 使用当前 Best Ask 作为 Sell Limit 入场价
LMT = Limit 限价单
STP = Stop 触发单
```

### 1. 使用 MKT 市价单

操作步骤：

1. 点击 Buy 或 Sell 下方的 MKT。
2. RiskManager 会使用当前市场价作为入场价。
3. 在图表上点击止损价。
4. 工具自动计算手数。
5. 工具发送市价入场单。
6. 入场成交后，工具发送止损单和可选止盈单。

适用场景：

想立即进场，同时让工具按点击的止损价自动计算仓位。

### 2. 使用 BID / ASK 快速限价单

Buy BID：

1. 点击 Buy 下方的 BID。
2. RiskManager 自动读取当前 Best Bid 作为入场价。
3. 在图表上点击止损价。
4. 工具自动计算手数。
5. 工具发送 Buy Limit 入场单。
6. 入场成交后，工具发送止损单和可选止盈单。

Sell ASK：

1. 点击 Sell 下方的 ASK。
2. RiskManager 自动读取当前 Best Ask 作为入场价。
3. 在图表上点击止损价。
4. 工具自动计算手数。
5. 工具发送 Sell Limit 入场单。
6. 入场成交后，工具发送止损单和可选止盈单。

注意：

如果当前 Best Bid 或 Best Ask 不可用，HUD 会显示提示，工具不会继续下单。

### 3. 使用 LMT 限价单

操作步骤：

1. 点击 Buy 或 Sell 下方的 LMT。
2. 在图表上点击入场价。
3. 在图表上点击止损价。
4. 工具自动计算手数。
5. 工具发送限价入场单。
6. 入场成交后，工具发送止损单和可选止盈单。

价格规则：

```text
Buy Limit 的入场价必须低于当前市场价。
Sell Limit 的入场价必须高于当前市场价。
```

### 4. 使用 STP Stop 单

操作步骤：

1. 点击 Buy 或 Sell 下方的 STP。
2. 在图表上点击入场触发价。
3. 在图表上点击止损价。
4. 工具自动计算手数。
5. 工具发送 Stop 入场单。
6. 入场成交后，工具发送止损单和可选止盈单。

价格规则：

```text
Buy Stop 的入场价必须高于当前市场价。
Sell Stop 的入场价必须低于当前市场价。
```

## 七、取消当前操作

如果点错了，或者不想继续当前下单流程：

点击 HUD 中的 Cancel / 取消。

默认情况下，它会清空当前选择的入场价、止损价、止盈价和手数，并回到等待下单状态。

注意：

默认 Cancel 只用于取消当前 HUD 选择流程，不等同于撤掉账户里已经挂出的所有订单。

如果你在设置中启用了订单和仓位处理模式，Cancel 会要求二次确认。第二次点击后，RiskManager 会处理当前账户、当前图表品种的订单和仓位。

使用该模式前，请确认当前账户、当前图表品种和当前仓位都是你想处理的对象。

## 八、仓位计算逻辑

RiskManager 使用以下逻辑计算手数：

```text
Tick 距离 = |入场价 - 止损价| / TickSize
单手风险 = Tick 距离 * 每 Tick 价值
下单手数 = 向下取整(止损金额 / 单手风险)
```

如果计算结果小于 1，则最少为 1 手。

示例：

```text
止损金额 = 250 美元
入场价到止损价距离 = 20 Tick
每 Tick 价值 = 0.50 美元

单手风险 = 20 * 0.50 = 10 美元
手数 = 250 / 10 = 25 手
```

## 九、RR 止盈逻辑

当 Enable RR Target 开启时，RiskManager 会根据 RR Ratio 自动计算止盈价。

做多：

```text
止盈价 = 入场价 + (入场价 - 止损价) * RR
```

做空：

```text
止盈价 = 入场价 - (止损价 - 入场价) * RR
```

示例：

```text
做多入场价 = 100
止损价 = 95
RR = 2

风险距离 = 5
止盈价 = 100 + 5 * 2 = 110
```

如果 Enable RR Target 关闭：

```text
不计算 TP。
不提交 TP 止盈单。
只提交入场单和止损单。
```

## 十、订单提交逻辑

RiskManager 当前使用普通订单实现入场、止损和止盈：

```text
Entry：Market / Limit / Stop，由下单模式决定。
SL：Stop 订单。
TP：Limit 订单，仅在启用 RR 止盈时创建。
```

一般流程：

1. 先提交 Entry 入场单。
2. Entry 成交后，再提交 SL 止损单和可选 TP 止盈单。
3. 如果启用 RR 止盈，SL 和 TP 使用 OCO 关联。
4. SL 成交后，工具会尝试取消 TP。
5. TP 成交后，工具会尝试取消 SL。

请注意：

SL / TP 是普通 Stop / Limit 订单，不是 ATAS 持仓线上原生可拖动的止损止盈控件。

## 十一、常见问题

### 1. HUD 没出现

检查 UI Style 是否为 HUD。

检查策略是否已经添加到当前图表。

检查 ATAS 底部策略列表是否启用 RiskManager。

### 2. HUD 显示中文乱码

将 HUD Language 改为 English。

### 3. 点击按钮后不能下单

检查是否已经填写有效授权码。

检查 HUD 状态栏是否显示授权失败、网络失败或授权过期。

检查策略是否启用。

检查是否选择了交易账户。

检查当前品种是否可交易。

检查 Tick Value 是否有效。

### 4. BID / ASK 点击后没有进入下单流程

当前 Best Bid 或 Best Ask 可能不可用。

请确认行情连接正常，并且当前品种有实时买卖价。

### 5. 提示止损价格无效

做多时止损必须低于入场价。

做空时止损必须高于入场价。

### 6. 提示 Limit 或 Stop 价格无效

```text
Buy Limit 必须低于市场价。
Sell Limit 必须高于市场价。
Buy Stop 必须高于市场价。
Sell Stop 必须低于市场价。
```

### 7. 自动手数看起来不对

优先检查每 Tick 价值是否正确。

如果自动识别不适合当前品种，请在 Tick Value ($) 中手动填写。

### 8. 为什么至少下 1 手

当计算出的手数小于 1 时，RiskManager 会按 1 手处理。请确认止损金额和止损距离是否适合当前品种，避免实际风险超过预期。

### 9. Cancel 后没有处理订单或仓位

检查是否启用了订单和仓位处理模式。

检查是否完成二次点击确认。

检查当前账户和当前图表品种是否正确。

检查当前账户和当前品种下是否确实有可处理的订单或仓位。

## 十二、实盘前检查清单

每次实盘使用前，建议确认：

1. 授权码有效。
2. 当前账户正确。
3. 当前品种正确。
4. 策略状态为 ON。
5. SL Amount 是本次愿意承担的最大亏损金额。
6. Tick Value 正确。
7. RR Target 是否按计划开启或关闭。
8. Order Entry Mode 是否符合当前操作习惯。
9. 已在模拟环境测试过当前品种的下单、成交、止损和止盈流程。
10. 使用 BID / ASK 前确认实时行情和买卖价正常。
11. 使用 Cancel 的订单和仓位处理模式前，确认当前图表就是你想处理的品种。

## 十三、风险提示

交易存在风险。RiskManager 只能按照输入参数和当前市场数据计算订单，不控制以下情况：

```text
滑点
跳空
网络延迟
交易所拒单
券商风控限制
ATAS 连接异常
行情数据异常
手动改动或取消订单
```

实盘前请务必使用模拟账户验证，并确认你理解每一种订单类型的行为。
